# Security policy

Please report suspected security vulnerabilities privately through GitHub's
security advisory feature instead of opening a public issue.

SubHooper verifies pinned VideoSubFinder and Python installer downloads with
SHA-256 before execution or extraction. Update packages are signed with the
project's Tauri updater key. The private signing key must never be committed.

Downloaded third-party components and optional online translation remain
subject to their respective projects' security policies and account terms.
